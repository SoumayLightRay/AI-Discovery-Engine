## Key Quotes

**On why items sit in wishlist:**
> "I keep forgetting whenever I have money, and when I run out of money, then I remember."
> "I start procrastinating. I keep start overthinking if I should actually buy it or not."

**On the core blocker — styling/versatility:**
> "I get confused if this will go with my other fits or not."
> "Whenever I shop, I try to get something which is very versatile, which goes with a lot of different kinds of clothing. So that is one of the major reasons for the delay."

**On reviews:**
> "If something had no reviews whatsoever? I mean then I would not go for it."
> "If it is a well-known brand, then I would go on their website and check there maybe."

**On return policy:**
> "That's like lots of hassle, like time." — return exists but he sees it as too much effort.

**On cross-platform comparison:**
> Checked the brand's website directly + Ajio. Does compare across platforms.

**On paying more for confidence:**
> "I would buy the one with the good reviews." — same product, different sellers, chooses the one with reviews.

**On what would help on wishlist:**
> "If it helps me compare products that are there in the wishlist." — wants comparison within wishlist.

---

## Key Findings

1. **Styling/versatility doubt is his PRIMARY blocker** — not price, not quality, not fit. "Will this go with my wardrobe?" This is a different confidence mechanism than fit/quality
2. **Procrastination loop** — revisits item every 20–30 days, overthinks, forgets, repeats. Classic high-intent stalled behaviour
3. **Social validation seeker** — "I take opinions from people, do you think this is nice?"
4. **Zero reviews = no buy** — but will check brand website as fallback
5. **Return policy = hassle, not a solution** — knows returns exist but considers them too much effort. This validates our root cause: users want to be confident BEFORE buying, not rely on returns after
6. **Confirms confidence > price** — would choose reviewed seller over unreviewed for same product
7. **Wants comparison within wishlist** — 3rd user to request comparison feature on wishlist page
8. **5 items in wishlist** — small wishlist, high-intent items, forgets and revisits cyclically
