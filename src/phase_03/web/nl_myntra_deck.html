Why 1: Users hesitate to move wishlist to cart. Prakhar revisits every 20-30 days.

Why 4: Returns stressful (93.5% neg). Prakhar: "lots of hassle, like time"

Part 5: Solution Rationale — RICE + 3-Level Test

Myntra Verified Confidence Layer — 3 Layers × 8 Components That Get Smarter With Every Purchase

Layer 1 — User-Generated Trust

📸 Verified Buyer Photos
Real photos ON wishlist card. 11/12 prefer over model.

⭐ Top Reviews on Wishlist
Most helpful reviews pulled directly. 9/12 require.

🔄 Return Clarity Badge
"✅ Easy Return" or "⚠️ Non-returnable" — prominent.

Layer 2 — Platform-Verified

🏅 Myntra Verified Badge
Quality, fit, photos independently verified. No competitor does this.

🔗 Cross-Seller Review Bridge
Zero-review → seller's other reviews. 3/6 validated.

🔀 Smart Compare
Side-by-side wishlisted items with all signals.

Layer 3 — Data Moat

📏 Brand Size Intelligence
"Roadster runs 1 size small" based on Myntra buyers. Proprietary.

🔁 Post-Purchase Flywheel
After delivery: "Match? Size? Quality?" → Brand Trust Index. Compounds.

Flywheel creates:

Photo Accuracy Rate · Size Intel · Seller Trust

How They Work Together

HAS Reviews →

Buyer Photos + Reviews + Size Intel + Return Badge → "Runs true to size. Buying."

ZERO Reviews →

Myntra Verified + Cross-Seller Bridge + Trust Score → "Verified AND seller 4.3★. Buying."

COMPARING →

Smart Compare side-by-side → "Item A: 94% photo match. Item B: unverified. Going with A."

MVP proves: Can platform-verified signals change "leave to compare" → "buy here now"?
